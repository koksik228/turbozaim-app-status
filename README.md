# turbozaim-app-status

Публичный remote-config («рубильник») приложения Turbozaim — iPhone и Android.

Приложение скачивает [`appstatus.json`](appstatus.json) при старте и при возврате из фона,
чтобы показать режим технических работ / увести пользователя на сайт, когда приложение
не может работать (поменялся бэкенд, нужно обновление и т.п.).

## Здесь НЕТ секретов

Только публичные флаги, тексты и ссылки. Никаких токенов/ключей/ПДн.

## Как включить «техработы»

**Обычный путь — не руками.** В основном репозитории приложения лежат кнопки:
`scripts/win/` для Windows и `scripts/mac/` для Mac. Они проверяют файл перед
публикацией и показывают, кого затронет изменение. Пошаговая инструкция для
владельца — `docs/ЕСЛИ-СЛОМАЛОСЬ.md` в основном репозитории.

**Запасной путь — правка прямо здесь на github.com**, если скрипта под рукой нет.
Он тоже описан в той инструкции.

## Схема v2: платформы гасятся раздельно

Правило слияния: **гасим, если активен общий флаг ИЛИ флаг своей платформы.**
Остальные поля платформенный блок перекрывает.

- «погасить обе» — один тумблер `maintenance.active`;
- «погасить только Android» — `platforms.android.maintenance.active`;
- комбинации «думал, что погасил всех, а погасил половину» не существует.

Верхний уровень оставлен зеркалом схемы v1: уже выпущенная сборка, которая про
`platforms` не знает, продолжает корректно читать общую секцию. Это важно, потому
что адрес этого файла вшит в бинарник и OTA-обновлений у приложения нет.

## Поля

| Поле | Назначение |
|---|---|
| `schemaVersion` | версия формата. Незнакомая версия приложение не блокирует — оно прочитает знакомые поля |
| `maintenance.active` | общий тумблер: гасит **обе** платформы |
| `maintenance.level` | `hard` (блокирующий экран) / `soft` (полоска сверху, приложение работает) |
| `maintenance.title` / `message` | тексты экрана |
| `maintenance.cta` | кнопка «Перейти на сайт» (приложение открывает только `*.turbozaim.ru`) |
| `minVersion.ios` / `minVersion.android` | минимальная версия по платформе; ниже — экран «Обновите приложение» |
| `updateUrl` | ссылка на App Store для старых сборок iPhone. Сейчас пусто: приложение ещё не опубликовано |
| `flags` | удалённые тумблеры фич (`registration`, `tbank`). Пока приложением не читаются |
| `platforms.ios` / `platforms.android` | платформенный блок: `maintenance` (те же поля) и `updateUrl` магазина своей платформы |

Приложение читает в платформенном блоке только `maintenance` и `updateUrl`.
Любое другое поле будет молча проигнорировано.

## Ссылки на магазины

- Android: `https://www.rustore.ru/catalog/app/ru.turbozaim.app` — карточка ещё не
  опубликована (адрес отдаёт 404), но формат адреса верный и заработает сам после публикации.
- iPhone: адрес появится после публикации в App Store. Ставить туда выдуманный
  номер нельзя — кнопка «Обновить» поведёт в никуда.

Подробности решения — ADR-018 и ADR-020 в основном репозитории приложения.
